# منة الله أحمد — الموقع الشخصي والمدونة

مدونة شخصية وموقع أعمال ثنائي اللغة لـ**منة الله أحمد**. التخصص الجامعي: **تقنيات الإنترنت — كلية تقنية المعلومات، جامعة طرابلس**؛ مع اهتمامات بتطوير الويب والموبايل والأنظمة الخلفية والذكاء الاصطناعي.

**الرابط:** https://mena626.github.io/personal-blog/

## الهوية البصرية

- لوحة الألوان المعتمدة من مرجع **YOUTH DAY BRANDING**:
  - **White** `#FFFFFF` — الخلفيات الرئيسية والبطاقات ومساحات القراءة.
  - **Yellow** `#FFD850` — الأزرار والحالات التفاعلية وعناصر التأكيد.
  - **Light Blue** `#009EFF` — العناصر التقنية والتفاصيل البارزة.
  - **Dark Blue** `#1A49AF` — الغلاف والعناوين والكتل الأساسية.
- تُستخدم درجات أزرق فاتح وداكن مشتقة من هذه الألوان لضبط التباين والقراءة.
- غلاف تقني متجاوب يضم نافذة كود تفاعلية مع ميلان محدود على المؤشر للأجهزة المناسبة، وحركات تدرج وظهور هادئة مع `prefers-reduced-motion`.
- الخط العربي **Cairo** والإنجليزي **DM Sans**. الشعار المنحني مع النقطة محفوظ في القائمة والتذييل وأيقونة المتصفح.
- المشاريع المنشورة وروابط المعاينة وCV وأعمال الفيديو محفوظة دون تغيير.

## الأقسام

1. **التعريف:** «أنا منة الله أحمد» — دراسة تقنيات الإنترنت، وتحليل الأفكار وتصميم التجارب وبناء الحلول.
2. **CV:** المسار العلمي والتقني، وصفحة cv.html قابلة للطباعة أو الحفظ PDF.
3. **المشاريع:** [ميزان](https://mizan-libya-demo.onrender.com) — قيد التطوير مع معاينة تجريبية، و[COSMOS](https://rawcdn.githack.com/MENA626/personal-blog/009f8918bfb3ff41165c9af129cdd845d0b28196/cosmos/index.html)، و[MATCHA MOOD | ماتشا مود](https://matcha-mood-ly.floot.app/) — تطبيق ويب منشور على Floot، والمدونة الشخصية.
4. **الفيديوهات:** [العمل الأول](https://youtu.be/hgrRXHWNMFQ) و[العمل الثاني](https://youtu.be/dF6-pAAfHgs)، بعد المشاريع مباشرة.
5. **التقنيات:** Laravel، PHP، Java، JavaScript، Flutter، Dart، OpenAI، Gemini، RAG، Embeddings، PostgreSQL، Supabase، pgvector، MySQL، Docker، Git، Linux. تُعرض 17 أيقونة ملونة ومُجاورة دون الاعتماد على تأثيرات Hover.
6. **المقالات:** أفكار لمقالات قادمة؛ ليست منشورات مكتملة.
7. **التواصل:** [GitHub MENA626](https://github.com/MENA626).

لا يتم نشر أرقام هواتف أو بريد غير مؤكد، ولا إضافة شهادات أو وظائف لم تُذكر.

## بنية الموقع

- index.html — صفحة كاملة مع CSS وJavaScript مضمنين لثبات النشر.
- styles.css وscript.js — نسخ المصدر، ويجب مزامنة تعديلاتها مع ما داخل index.html.
- cv.html — السيرة الذاتية القابلة للطباعة.
- cosmos/index.html — مشروع COSMOS.
- check.html — فحص GitHub Pages.

## أسلوب النصوص
