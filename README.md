# منة الله أحمد — الموقع الشخصي والمدونة

موقع أعمال ثنائي اللغة لمهندسة البرمجيات **منة الله أحمد**، خريجة كلية تقنية المعلومات بجامعة طرابلس.

**الرابط:** https://mena626.github.io/personal-blog/

## الهوية البصرية

- غلاف سينمائي متدرّج بالألوان الرسمية الجديدة: البنفسجي العميق `#3F0B78`، الموف المضيء `#BD4BF8`، والبرتقالي `#FE5000`، مع البنفسجي الليلي `#261A66` والأبيض `#FFFFFF`.
- صورة الغلاف: `assets/violet-ambient-cover.svg`، مع حركة ظهور هادئة وخلفية بديلة.
- أقسام بيضاء وبطاقات مريحة للقراءة، ولمسات برتقالية مدروسة، دون رسومات طفولية.
- الخط الأساسي **Cairo**؛ الإنجليزية **DM Sans**.
- شعار M الهندسي ما زال المستخدم في الغلاف والقائمة والتذييل إلى حين توفير صورة الشعار البديل بصيغة يمكن رفعها.


## الأقسام

1. **التعريف:** المهندسة منة الله أحمد ورؤيتها.
2. **CV:** المسار العلمي والتقني، وصفحة cv.html قابلة للطباعة أو الحفظ PDF.
3. **المشاريع:** [ميزان](https://mizan-libya-demo.onrender.com) — قيد التطوير مع معاينة تجريبية متاحة، و[COSMOS](https://rawcdn.githack.com/MENA626/personal-blog/009f8918bfb3ff41165c9af129cdd845d0b28196/cosmos/index.html)، والمدونة الشخصية.
4. **التقنيات:** Laravel، PHP، Java، JavaScript، Flutter، Dart، OpenAI، Gemini، RAG، Embeddings، PostgreSQL، Supabase، pgvector، MySQL، Docker، Git، Linux.
5. **الفيديوهات:** [العمل الأول](https://youtu.be/hgrRXHWNMFQ) و[العمل الثاني](https://youtu.be/dF6-pAAfHgs)، مع معاينتين وتشغيل عند الضغط.
6. **المقالات:** أفكار لمقالات قادمة؛ ليست منشورات مكتملة.
7. **التواصل:** [GitHub MENA626](https://github.com/MENA626).

لا يتم نشر أرقام هواتف أو بريد غير مؤكد، ولا إضافة شهادات أو وظائف لم تُذكر.

## بنية الموقع

- index.html — صفحة كاملة مع CSS وJavaScript مضمنين لثبات النشر.
- styles.css وscript.js — نسخ المصدر، ويجب مزامنة تعديلاتها مع ما داخل index.html.
- cv.html — السيرة الذاتية القابلة للطباعة.
- cosmos/index.html — مشروع COSMOS.
- check.html — فحص GitHub Pages.
