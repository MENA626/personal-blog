# منة الله — مدونة وموقع أعمال مهندسة برمجيات ✳

مدونة «منة الله» وموقع أعمال عربي بتصميم تحريري عصري وحركات تفاعلية، يعمل على الكمبيوتر والموبايل.


## هوية الموقع الحالية

موقع أعمال (Portfolio) ومدونة تقنية لمهندسة برمجيات خريجة كلية تقنية المعلومات بجامعة طرابلس، يحتوي على الأقسام:

- من أنا والمؤهل العلمي
- المشاريع: الموقع نفسه مشروع موثق، والبطاقات الأخرى **أماكن جاهزة للتخصيص وليست أعمالاً مزعومة**
- المهارات والخبرات والدورات: عناصر تمهيدية حتى تصل البيانات الحقيقية
- تدوينات تجريبية مع البحث والتصفية ونافذة القراءة
- وسائل التواصل: حساب GitHub حقيقي، وبقية المعلومات أماكن انتظار فقط

### الهوية البصرية الجديدة

هوية هندسية احترافية بالعربية والإنجليزية دون أي شخصية كرتونية أو عناصر مرحة، بألوان الصورة التي اختارتها صاحبة الموقع:

- **Deep Green:** `#205C43` — العناوين واللوحة الهندسية والأزرار.
- **Off White:** `#FFFFFF` — الخلفية الهادئة.
- **Rose Pink:** `#DB628B` — لمسات التفاعل وإبراز العناصر.
- الأسود والأبيض والرماديات للقراءة والتباين فقط.

الغلاف أصبح لوحة ثنائية الأعمدة: نص تعريفي واضح على خلفية فاتحة، ومخطط تجريدي أنيق لمراحل تحليل الأنظمة وتصميمها وبنائها، مع حركات محدودة تحترم إعداد تقليل الحركة.

اسم «منة الله» يبقى كرسم نصي من خط ثمانية دون نشر ملفات الخط الخام؛ باقي الخطوط تستخدم ثمانية عند توفره محليًا وتتحول لبدائل مرخصة.

### ما نحتاجه لتخصيص السيرة والملف المهني

1. الاسم المراد عرضه (بالعربية والإنجليزية).
2. نبذة شخصية بالمعلومات التي ترغبين بنشرها.
3. أسماء المشاريع، روابطها، وصف مختصر، والتقنيات المستخدمة.
4. لغات البرمجة وأطر العمل وقواعد البيانات والأدوات التي تعرفينها.
5. الخبرات العملية، التدريب، الشهادات، وسنواتها إن وجدت.
6. البريد ورقم الهاتف ورقم WhatsApp وLinkedIn التي **توافقين على نشرها علناً**، فالريبو وGitHub Pages عامّان.

لا تنشري كلمات مرور أو رموز دخول أو بيانات خاصة في كود الموقع.

## المميزات

- تصميم RTL عربي متجاوب بأسلوب Editorial مع رسومات متحركة بـ CSS
- تأثير ثلاثي الأبعاد عند تحريك المؤشر، وحركات ظهور أثناء التمرير
- الوضع الداكن والفاتح مع حفظ الاختيار
- تدوينات تفاعلية في نافذة قراءة، مع رابط مشاركة مباشر
- تصفية حسب التصنيف والبحث في التدوينات
- دعم لوحة المفاتيح وتقليل الحركة من إعدادات النظام
- موقع ثابت بالكامل: بدون قواعد بيانات أو خادم أو أدوات بناء

## الملفات

| الملف | وظيفته |
| --- | --- |
| \`index.html\` | هيكل الموقع والأقسام |
| \`styles.css\` | التصميم، الاستجابة والحركات |
| \`script.js\` | المقالات والتفاعل والبحث |

## إضافة / تعديل تدوينة

افتح \`script.js\` ثم عدّل مصفوفة \`posts\` الموجودة بأول الملف. المحتوى الحالي **أمثلة تجريبية** يمكن تغييرها بالكامل. لكل مقال: \`id\` (اسم قصير فريد بالإنجليزي)، \`title\`، \`description\`، \`category\`، \`categoryName\`، \`date\`، \`readTime\`، \`theme\`، \`illustration\`، و\`paragraphs\`. لتغيير الاسم ونبذة "من أنا" وروابط التواصل، عدّل \`index.html\`.

## معاينة الموقع

للمعاينة على جهازك، افتح \`index.html\` في المتصفح؛ لا توجد خطوة تثبيت.

### نشر معاينة مجانية عبر GitHub Pages

1. افتح [Repository Settings → Pages](https://github.com/MENA626/personal-blog/settings/pages).
2. عند **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع \`main\` والمجلد \`/(root)\`، ثم اضغط **Save**.
4. بعد اكتمال النشر، سيكون الرابط:
   **https://mena626.github.io/personal-blog/**

> تنبيه: لأن هذا المستودع Public، فإن معاينة GitHub Pages ستكون عامة وليست محمية بكلمة مرور. إذا احتجت معاينة خاصة، نقدر نستخدم استضافة بدعم حماية الوصول لاحقاً.

## تخصيص الألوان

متغيرات الألوان موجودة في بداية \`styles.css\` داخل \`:root\`. تستطيع تبديل ألوان الخلفية والنصوص واللمسات بسهولة.


## خط ثمانية (Thmanyah)

هيّأنا خطوط الموقع بحيث يفضّل الخطوط الأصلية إذا كانت مثبّتة **محلياً** على جهاز الزائر:

- `Thmanyah Sans` لعناصر الواجهة والقوائم.
- `Thmanyah Serif Display` للعناوين الكبيرة.
- `Thmanyah Serif Text` لقراءة المقالات.

تحميل وتثبيت الخط على جهازك: https://font.thmanyah.com/

**مهم:** استخدمنا خط ثمانية الأصلي لإنشاء رسم نصي ثابت لاسم «منة الله» فقط، وهو ظاهر للجميع. أما نصوص الصفحة والعناوين الأخرى فتفضّل خط ثمانية إذا كان مثبتًا على جهاز الزائر، وتستعمل خطوطًا احتياطية عند عدم وجوده. لم نرفع ملفات OTF/WOFF2 الأصلية إلى المستودع العام. الترخيص الرسمي يسمح بالاستخدام الشخصي والتجاري، لكنه يقيّد إعادة استضافة ملفات الخط أو إتاحتها مستقلةً للتنزيل، لذلك لم نرفع أي ملفات خط للمستودع العام ولم نستخدم مرايا CDN غير رسمية. راجع https://font.thmanyah.com/licenses ولتضمين الخط للجميع بطريقة معتمدة تواصل مع ثمانية للحصول على وسيلة توزيع/تضمين متوافقة مع الترخيص.

## المظهر المعتمد

المدونة تعرض شخصية مهنية واضحة **بدون قطط أو رسومات كرتونية**. ألوانها الأساسية الأخضر الداكن `#205C43`، والبينك `#DB628B`، وخلفية بيضاء ناصعة `#FFFFFF`، مع لمسات أخضر فاتح ووردي فاتح في الأقسام والبطاقات. يتضمن الموقع العربية والإنجليزية، ومشروع ميزان ومهارات منة الله التقنية.
