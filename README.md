# منة الله أحمد — الموقع الشخصي والمدونة

موقع أعمال ثنائي اللغة يعرض الملف المهني لـ**منة الله أحمد** في هندسة البرمجيات، بعد إكمال الدراسة بكلية تقنية المعلومات بجامعة طرابلس.

**الرابط:** https://mena626.github.io/personal-blog/

## الهوية البصرية

- لوحة ألوان SaaS المعتمدة: **الأزرق** `#136CFC`، **الكحلي** `#152641`، **الليموني** `#C3F84A`، **الأزرق الفاتح** `#E8F4FC`، مع الأبيض للقراءة.
- غلاف هندسي متجاوب يضم واجهة كود أصلية مبنية بـHTML/CSS، وحركة إمالة لطيفة عند تحريك المؤشر على الأجهزة المناسبة.
- مؤثرات خفيفة في التمرير والأزرار والبطاقات، مع دعم `prefers-reduced-motion` وعدم اختراع أرقام إنجازات.
- الخط العربي **Cairo**، والإنجليزي **DM Sans**. الشعار المنحني مع النقطة مستمر في القائمة والتذييل وأيقونة المتصفح.
- الأقسام الرئيسية هادئة بدرجات الأبيض والأزرق الفاتح، مع بطاقات تقنية واضحة وبروز ليموني للأزرار.

## الأقسام

1. **التعريف:** ملف منة الله أحمد المهني ونهج العمل في هندسة البرمجيات.
2. **CV:** المسار العلمي والتقني، وصفحة cv.html قابلة للطباعة أو الحفظ PDF.
3. **المشاريع:** [ميزان](https://mizan-libya-demo.onrender.com) — قيد التطوير مع معاينة تجريبية، و[COSMOS](https://rawcdn.githack.com/MENA626/personal-blog/009f8918bfb3ff41165c9af129cdd845d0b28196/cosmos/index.html)، و[MATCHA MOOD | ماتشا مود](https://matcha-mood-ly.floot.app/) — تطبيق ويب منشور على Floot، والمدونة الشخصية.
4. **التقنيات:** Laravel، PHP، Java، JavaScript، Flutter، Dart، OpenAI، Gemini، RAG، Embeddings، PostgreSQL، Supabase، pgvector، MySQL، Docker، Git، Linux.
5. **الفيديوهات:** [العمل الأول](https://youtu.be/hgrRXHWNMFQ) و[العمل الثاني](https://youtu.be/dF6-pAAfHgs)، مع معاينتين وتشغيل عند الضغط.
6. **المقالات:** أفكار لمقالات قادمة؛ ليست منشورات مكتملة.
7. **التواصل:** [GitHub MENA626](https://github.com/MENA626).

لا يتم نشر أرقام هواتف أو بريد غير مؤكد، ولا إضافة شهادات أو وظائف لم تُذكر.

## بنية الموقع

- index.html — صفحة كاملة مع CSS وJavaScript مضمنين لثبات النشر.
- styles.css وscript.js — نسخ المصدر، ويجب مزامنة تعديلاتها مع ما داخل index.html.
- cv.html — السيرة الذاتية القابلة للطباعة.
- cosmos/index.html — مشروع COSMOS.
- check.html — فحص GitHub Pages.

## أسلوب النصوص

تعتمد العربية صياغة مهنية محايدة بالمبني للمجهول أو المذكر العام دون مخاطبة الزائر بصيغة المؤنث أو تقديم النصوص بمنظور المتكلم. تنطبق على الصفحة والسيرة الذاتية والتفاعلات.
